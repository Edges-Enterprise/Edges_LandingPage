Authentication

How to Generate (TOKEN)



The Basic Authentication Is Use To Generate (TOKEN)
It should be passed as a concatenated string like this username:password
Please use the following details for authentication
Username: Your Lizzysub Username
Password: Your Lizzysub Password
convert it to base64(username:password) use it to gerenerate token




Enpoint URL

https://lizzysub.com/api/user
Code Sample

                 $ch = curl_init();
                curl_setopt($ch, CURLOPT_URL, "https://lizzysub.com/api/user");
                curl_setopt($ch, CURLOPT_POST, 1);
                curl_setopt($ch, CURLOPT_RETURNTRANSFER, 1);
                curl_setopt(
                   $ch, CURLOPT_HTTPHEADER, [
                        "Authorization: Basic ".base64_encode('username:password'),
                    ]
                );
                $json = curl_exec($ch);
                curl_close($ch);

The webhook service enables Lizzysub to send your system an update on certain activities. Such activities will include:




Transaction status update

The is usually sent to a URL you will provide to us via your Lizzysub dashboard. Please see

IMPORTANT NOTES:

To receive the Lizzysub callback requests, the below refers:



Make sure to update your callback URL on your Lizzysub dashboard when logged in on the website.
The request data will come as a JSON with three parent keys: “request-id” , “status” and "response" (and maybe more)
The “request-id” parent key will send u back the unique request-id you sent us earlier.
The “status” parent key will define if the transaction is success or fail.
The “response” parent key means the API Response.
